This is a design fixture for **Pages**, with fixed source names and refresh times. It does not connect to a Page or change its sources. [Open the full-width study](/pages-sources-line) to compare desktop and phone layouts.

<PagesSourcesLineExample embedded />

## Behavior

- No sources: render nothing, keeping today's title and body spacing.
- One or two: show each name and its last-set time, with a small data icon attached to the source name to distinguish the entry from a subtitle.
- Three: show the names when there is room; use the summary on narrow layouts.
- More: show the accepted freshness summary, a count with newest/oldest last-set times.
- Compare the original unlabeled line with a separate text label and an icon on each source name. The last option is the current direction. These are noninteractive metadata; no button styling or implied action.
- Keep the line as plain text, identical for readers and editors. No panel or binding controls in this design.
- Source order is alphabetical and does not change on refresh. Old dates get no warning color because a Page has no expected refresh interval.

The title, typography, and article spacing mirror `apps/pages/viewer/style.css`; the fixture's controls are outside the Page. The production implementation reads the Page session's source store and the host's last-set timestamp. A first version says **added**, later versions say **refreshed**, including a refresh that finds unchanged rows. “Added” means added as a Page source, not the asset upload time or the date of the data. The summary covers both additions and refreshes, so it says “newest” and “oldest.”
