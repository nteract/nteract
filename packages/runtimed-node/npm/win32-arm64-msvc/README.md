# @runtimed/node-win32-arm64-msvc

Native Windows ARM64 MSVC binding for `@runtimed/node`.

This package contains the compiled N-API `.node` binary used by
`@runtimed/node` on Windows ARM64 systems. Install `@runtimed/node` directly
unless you are debugging or publishing the platform package itself.

```bash
npm install @runtimed/node
```
